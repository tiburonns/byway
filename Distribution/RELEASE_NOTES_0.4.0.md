# Byway 0.4.0

## Español

- Aplicación localizada en español e inglés con selector de idioma en Ajustes.
- 30 atajos firmados en español y 30 en inglés.
- Archivo `Byway-Schema-3.byway` con las 36 variables del flujo completo.
- Los cambios de modo guardan automáticamente la fecha, la hora y la última acción sin solicitar confirmación.
- Fuentes de AltStore en ambos idiomas y una compilación preparada para volver a firmarse.

Inicio rápido: instala el IPA, abre Byway, importa el Esquema 3, instala una colección de atajos y ejecuta **BYWAY — Inicializar sistema**.

## English

- English and Spanish app localization with an in-app language selector.
- 30 signed Shortcuts in English and 30 in Spanish.
- `Byway-Schema-3.byway` containing all 36 variables for the complete workflow.
- Mode changes automatically save the date, time, and last action without a confirmation prompt.
- AltStore sources in both languages and a build prepared for re-signing.

Quick start: install the IPA, open Byway, import Schema 3, install one Shortcut collection, and run **BYWAY — Initialize System**.

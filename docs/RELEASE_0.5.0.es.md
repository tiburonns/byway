# byway 0.5.0

**Español · [English](RELEASE_0.5.0.md)**

- Vista previa de un archivo antes de aplicar cambios, incluyendo claves omitidas/sobrescritas/eliminadas, carpetas y tamaño de adjuntos.
- Exportación e importación opcional de copias `.bywaye` cifradas con passphrase.
- Posibilidad de deshacer la última importación exitosa desde Ajustes intercambiando de forma segura el estado anterior y el importado.
- Compatibilidad completa con archivos `.byway` sin cifrar y con las acciones existentes de Shortcuts.

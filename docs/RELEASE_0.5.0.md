# byway 0.5.0

- Preview an archive before any data changes, including skips, overwrites, removals, folders, and attachment size.
- Export and import optional passphrase-encrypted `.bywaye` backups.
- Undo the latest successful import from Settings; the prior and imported states can be swapped safely.
- Preserve full compatibility with existing unencrypted `.byway` archives and Shortcuts actions.
